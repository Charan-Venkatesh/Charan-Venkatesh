# Contributing to Charan-Venkatesh

Thank you for your interest in contributing to this project! Here are some guidelines to help you get started.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature or bug fix
4. Make your changes
5. Test your changes thoroughly
6. Submit a pull request

## Development Setup

### Prerequisites
- Python 3.8 or higher
- Jupyter Notebook
- Git

### Installation
```bash
git clone https://github.com/Charan-Venkatesh/Charan-Venkatesh.git
cd Charan-Venkatesh
pip install jupyter notebook pandas numpy
```

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Testing

- Test your changes before submitting
- Ensure Jupyter notebooks can be executed without errors
- Validate that any new features work as expected

## Submitting Changes

1. Ensure your code follows the project's style guidelines
2. Test your changes thoroughly
3. Update documentation if necessary
4. Submit a pull request with a clear description of your changes

## Reporting Issues

When reporting issues, please include:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs actual behavior
- Your environment details (OS, Python version, etc.)

## Questions?

Feel free to open an issue for any questions about contributing.
